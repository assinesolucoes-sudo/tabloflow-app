Legenda do wireframe
  • Elementos cinza / tracejados representam placeholders · não são parte da identidade visual final.
  • Cores semânticas (verde · amarelo · vermelho · azul) representam categoria de mensagem (sucesso · alerta · erro · info), não paleta definitiva — serão redefinidas quando Frente A for ativada.
  • Stepper: cinza = travada · branco com outline = ativa · verde = concluída.
  • Anotações em itálico marrom são notas ao Arquiteto/Claude Code sobre gatilhos, bloqueios e warnings da Spec · não aparecem no app final.
  • Cada tela corresponde a um estado discreto do fluxo · §13.2 aplicado (etapa N só fica disponível quando N-1 concluída · edição invalida cascata · etapas concluídas mostram resumo compacto).
  • Este wireframe foca fluxo e estrutura de tela, não estética. Aprovação cosmética acontece na Frente A.
