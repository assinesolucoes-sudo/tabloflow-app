PROPÓSITO A V4 revela como um total é composto: qual é a participação de cada elemento dentro do todo, como essa composição se comporta em diferentes medidas, e qual é o grau de concentração ou pulverização do total. Pergunta central: "Dentro de um total, quanto cada elemento representa?" NÃO analisa movimento, NÃO compara estados no tempo, NÃO acompanha sequências. Analisa FORMA — é a visão de estrutura do TabloFlow. --- ## 3. OS 3 MODOS DE ANÁLISE ### Modo 1 · Composição Simples - Calcula participação % e ranking para cada elemento - Sem classificação ABC - Quando usar: entender estrutura sem priorização ### Modo 2 · Curva ABC - Tudo do Modo 1 + classificação por concentração acumulada - Limiares padrão (editáveis): A = 0–80% · B = 80–95% · C = 95–100% - Quando usar: priorização, gestão de portfólio, foco operacional ### Modo 3 · Comparação de Distribuição - Tudo do Modo 2 aplicado a cada medida separadamente - Compara posição (classe ABC) de cada elemento entre medidas - Destaca quem muda de classe entre medidas (ex: Classe A em Receita, Classe B em Margem) - Quando usar: análise de rentabilidade, eficiência, risco de concentração --- ## 4. ESTRUTURA DE ENTRADA A base pode ter medidas organizadas de dois modos (detectado pela IA, confirmado pelo usuário): ### Por Coluna - Cada medida é uma coluna separada - Ex: PRODUTO | RECEITA | CUSTO | MARGEM - Motor lê diretamente — cada coluna é uma medida ### Por Linha - Medidas empilhadas em coluna única de valor - Ex: PRODUTO | TIPO_MEDIDA | VALOR (onde TIPO_MEDIDA = "Receita", "Custo", "Margem") - Motor faz pivot antes de processar — transforma linhas em colunas de medida - ATENÇÃO: o pivot deve preservar todos os agrupadores — registros sem valor para uma medida específica recebem 0, não são descartados ### Ambígua - Estrutura não conclusiva → IA sinaliza → usuário decide manualmente --- ## 5. FLUXO DE ETAPAS ### Etapa 1 — Upload, Estrutura e Modo de Análise O usuário sobe o arquivo. LÓGICA TÉCNICA — CÁLCULOS ### Cálculos comuns aos 3 modos | Campo calculado | Fórmula | Observação | |-----------------|---------|------------| | Valor Agregado | SUM(medida) GROUP BY agrupador | Consolida todos os registros com o mesmo agrupador | | Total Geral | SUM(Valor Agregado) | Base de referência — calculado por medida | | Participação (%) | Valor Agregado ÷ Total Geral × 100 | Sempre soma 100% dentro de cada dimensão e medida | | Ranking | ORDER BY Valor Agregado DESC | Posição 1 = maior valor. Empate por ordem alfabética | | Participação Acumulada (%) | SUM(Participação) progressivo sobre o ranking | Base para classificação ABC nos Modos 2 e 3 | ### Cálculos específicos por Modo | Modo | Cálculo adicional | Output específico | |------|-------------------|-------------------| | Modo 2 · Curva ABC | Classe ABC = A se Acum ≤ limiar_A · B se Acum ≤ limiar_B · C caso contrário | Classe por elemento por medida | | Modo 3 · Comparação | Classe ABC calculada independentemente para cada medida | Mapa de divergência: elementos que mudam de classe entre medidas | | Modo 3 · Comparação | Delta de Ranking = Ranking(Medida A) − Ranking(Medida B) | Identifica elementos que sobem ou caem no ranking entre medidas | ### REGRA CRÍTICA — Soma das participações: A soma das participações percentuais deve ser exatamente 100% após arredondamento. Aplicar ajuste no último elemento se necessário. --- ## 7. LIMITADORES TÉCNICOS 1. **Medidas não aditivas**: médias, percentuais e índices não podem ser somados. Motor detecta via classificação semântica do MotorResult e alerta antes de processar. Solução: usar a medida base (ex: Receita Total) em vez da medida derivada (ex: Ticket Médio). 2. **Valores negativos**: total pode ser próximo de zero ou negativo — participação % instável. Motor detecta e alerta. Opções: valor absoluto, filtrar negativos, nota na exportação. 3. **Alta cardinalidade**: agrupadores com > 100 valores únicos → Curva ABC perde legibilidade. Motor processa normalmente mas IA emite alerta. 4. **Registros duplicados**: inflam o valor agregado e distorcem participações e rankings. Motor detecta via MotorResult e alerta. Usuário decide: deduplicar, somar ou tratar como erro. 5. **Modo 3 com escalas incomparáveis**: comparar R$ milhões com unidades gera rankings válidos individualmente mas potencialmente enganosos. IA alerta e sugere normalização. 6. **Total geral zero**: comportamento a definir — mensagem de erro ou bloqueio de processamento. (Pendência em aberto — implementar como erro bloqueante por segurança.) --- ## 8.
