# Motor de Upload — Especificação Técnica ## Responsabilidade Receber, validar, interpretar e normalizar qualquer arquivo enviado pelo usuário. Produz um UploadResult padronizado consumido pelo Motor Base. ## Arquivos Suportados - Excel (.xlsx, .xls) — uma ou múltiplas abas - CSV (.csv) — separador auto-detectado (vírgula, ponto-e-vírgula, tab) - Múltiplos arquivos simultâneos (ex: Base A + Base B para V1) ## Responsabilidades do Motor de Upload 1. Aceitar um ou mais arquivos por chamada 2. Detectar formato automaticamente pela extensão e conteúdo 3. Detectar encoding (UTF-8, Latin-1, etc.) 4. Detectar separador em CSV automaticamente 5. Listar abas disponíveis em arquivos Excel multi-aba 6. Ler a aba selecionada (ou aba única, se houver apenas uma) 7. Detectar linha de cabeçalho automaticamente 8. Retornar preview das primeiras 5 linhas 9. Retornar lista de colunas com tipo inferido 10. Retornar contagem de linhas 11. Nunca modificar os dados — apenas ler e descrever ## Contrato de Saída — UploadResult (Pydantic) ```python from pydantic import BaseModel from typing import Optional import pandas as pd class ColumnInfo(BaseModel): name: str # nome original da coluna inferred_type: str # "numeric", "text", "date", "boolean", "mixed" null_count: int # quantidade de valores nulos unique_count: int # quantidade de valores únicos sample_values: list[str] # até 3 valores de exemplo (como string) class UploadResult(BaseModel): file_name: str # nome do arquivo original file_format: str # "xlsx", "xls", "csv" sheet_name: Optional[str] # nome da aba (None se CSV) available_sheets: list[str] # lista de abas disponíveis (vazia se CSV) row_count: int # total de linhas (sem cabeçalho) column_count: int # total de colunas columns: list[ColumnInfo] # metadados por coluna preview: list[dict] # primeiras 5 linhas como lista de dicts encoding_detected: str # encoding detectado separator_detected: Optional[str] # separador detectado (apenas CSV) warnings: list[str] # avisos não-fatais (ex: "coluna sem nome renomeada") errors: list[str] # erros fatais que impedem leitura success: bool # True se leitura foi bem-sucedida arquivo_bytes: Optional[bytes] = None # bytes do arquivo original (Bloco V-0c) — consumido pelo Motor Base para carregar o DataFrame completo.
